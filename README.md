# منصة إدارة العمليات ومهام الفريق والنظام المحاسبي المتكامل (v5.1.3)

تطبيق ويب تقدمي (PWA) باللغة العربية (RTL) لإدارة مهام الفريق، متابعة الطلبات والمناديب، وإدارة الحسابات المالية (ERP مبسط ومتكامل) مع دعم تعدد الشركات والمتاجر والعمل دون اتصال.

## أبرز المزايا في الإصدار 5.1.3
1. **إرسال الفاتورة بصيغة PDF مباشرة للعميل بضغطة زر**: توليد ملف PDF عالي الدقة باللغة العربية ومشاركته فوراً مع العميل عبر واتساب أو مشاركة النظام دون الحاجة لحفظه يدوياً أولاً.
2. **تصنيف الطلبات (مستعجل، VIP، قابل للكسر، هدية، توصيل بوقت محدد، عادي)**: إمكانية تحديد تصنيف الطلب عند الإنشاء أو التعديل مع فلترة سريعة وتمييز بصري وإشعار للمندوب.
3. **فلترة متقدمة وشاملة في شاشة المهام**: بحث فوري، فلترة حسب الموظف، الأولوية، حالة الموعد (متأخرة، اليوم، غداً، هذا الأسبوع، بدون موعد)، النوع (فردية، جماعية، بمسار عمل)، الفترة الزمنية، والترتيب الذكي.
4. **حزمة النظام المحاسبي المبسط المتكامل**: يشمل الملخص المالي وصافي السيولة، دفتر القيود وسندات القبض والصرف (مع طباعة ومشاركة السند PDF)، أرصدة الصناديق والحسابات البنكية، حسابات التجار والموردين، عهد المناديب، والمصروفات والأرباح والخسائر.
5. **تقسيم الإعدادات وصلاحيات التبويبات الفرعية**: تبويبات فرعية وأقسام قابلة للطي (أكورديون) مع توزيع الصلاحيات لكل موظف بدقة.
